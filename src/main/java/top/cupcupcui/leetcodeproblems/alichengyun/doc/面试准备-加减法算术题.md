# 第二题：生成100道加减法算术题

## 题目要点背诵

### 核心限制条件（必须记住）
1. **加法题**：
   - 和 ≤ 100
   - 加数不能为0
   - 两个数都必须是正整数

2. **减法题**：
   - 被减数 ≤ 100
   - 结果 > 0（必须为正数）
   - 被减数 > 减数

3. **通用要求**：
   - 总共100道题
   - 不能重复
   - 两个文件：题目文件、题目+答案文件

## 暴力求解法（背诵版）

### 记忆口诀：
> "随机生成 → 合法性检查 → 去重判断 → 文件写入"

### 具体步骤（按顺序记忆）：

#### 第一步：初始化数据结构
```java
// 必须记住的：
Set<String> questions = new HashSet<>();  // 用于去重
Random random = new Random();
```

#### 第二步：循环生成（while循环直到100道）
```java
while(questions.size() < 100) {
    // 1. 随机决定生成加法还是减法（50%概率）
    boolean isAddition = random.nextBoolean();

    // 2. 生成题目字符串和答案
    String question = generateQuestion(isAddition, random);

    // 3. 检查是否重复（Set自动处理）
    if(questions.add(question)) {  // 如果成功添加，说明不重复
        // 4. 写入两个文件
        writeToFile(question, isAddition);  // 只写题目
        writeToFileWithAnswer(question, calculateAnswer(question));  // 写题目+答案
    }
}
```

#### 第三步：题目生成方法（背诵关键逻辑）
```java
// 生成加法题
num1 = random.nextInt(99) + 1;  // 1-99
num2 = random.nextInt(100 - num1) + 1;  // 确保和 ≤ 100
return num1 + " + " + num2 + " = ";

// 生成减法题
num1 = random.nextInt(99) + 1;  // 1-99（被减数）
num2 = random.nextInt(num1) + 1;  // 1到num1-1（确保结果>0）
return num1 + " - " + num2 + " = ";
```

## 面试时快速记忆要点

### 关键数据结构（必须写出来）：
- `HashSet<String>`：自动去重
- `Random`：生成随机数

### 核心算法逻辑（按顺序）：
1. **随机选择运算符**：`random.nextBoolean()`（true=加法，false=减法）
2. **生成数字**：
   - 加法：`num2 ≤ 100 - num1`
   - 减法：`num2 < num1`
3. **去重**：利用Set的`add()`方法返回值判断
4. **文件写入**：使用`BufferedWriter`或`FileWriter`

### 边界条件（背诵）：
- 加数不能为0 → 随机数从1开始
- 加法和不超100 → `num2 ≤ 100 - num1`
- 减法结果>0 → `num2 < num1`
- 被减数≤100 → `num1 ≤ 100`

## 面试话术模板

**当被问到这道题时，可以这样回答：**

> "这道题我的思路是使用暴力法配合Set去重。首先我会创建一个HashSet来存储已经生成的题目，这样可以自动处理重复问题。然后使用while循环直到生成100道不重复的题目。
>
> 在每次循环中，我会先随机决定是生成加法还是减法题。对于加法题，我会先随机生成第一个数（1-99），然后第二个数的范围是1到(100-第一个数)，确保和不超过100。对于减法题，我会生成被减数（1-99），然后减数的范围是1到被减数减1，确保结果大于0。
>
> 生成题目后，我会尝试将其加入Set中，如果add方法返回true，说明这是一个新题目，我就把它写入两个文件：一个只写题目，另一个写题目和答案。如果返回false，说明重复了，就跳过这次循环继续下一次。
>
> 这个方案的时间复杂度主要是O(n)，其中n是100，因为每次生成题目和检查重复的耗时是常数级的。空间复杂度是O(n)，用于存储题目集合。"

## 代码模板（面试时先写框架）

```java
// 第一步：导入包
import java.io.*;
import java.util.*;

// 第二步：定义类和主方法
public class MathProblemsGenerator {
    public static void main(String[] args) {
        Set<String> questions = new HashSet<>();
        Random random = new Random();

        // 创建文件写入器
        try (BufferedWriter questionWriter = new BufferedWriter(new FileWriter("questions.txt"));
             BufferedWriter answerWriter = new BufferedWriter(new FileWriter("answers.txt"))) {

            while(questions.size() < 100) {
                boolean isAdd = random.nextBoolean();
                String question = generateQuestion(isAdd, random);

                if(questions.add(question)) {
                    // 计算答案
                    int answer = calculateAnswer(question);

                    // 写入文件
                    questionWriter.write(question);
                    questionWriter.newLine();
                    answerWriter.write(question + answer);
                    answerWriter.newLine();
                }
            }
        } catch(IOException e) {
            e.printStackTrace();
        }
    }
}
```

剩下的generateQuestion和calculateAnswer方法可以根据上面的逻辑现场补全。
