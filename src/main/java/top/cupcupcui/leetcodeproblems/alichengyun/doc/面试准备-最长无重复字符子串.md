# 第六题：最长无重复字符子串
package top.cupcupcui.leetcodeproblems.alichengyun;

public class ProblemList {
    /**
     * ６、给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。
     * 示例 1:
     * 输入: s = "abcabcbb"
     * 输出: 3
     * 解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
     * 示例 2:
     * 输入: s = "bbbbb"
     * 输出: 1
     * 解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
     * 示例 3:
     * 输入: s = "pwwkew"
     * 输出: 3
     * 解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     *   请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
     * 难度：简单
     */
}

## 题目要点背诵

### 核心概念理解（必须记住）

**什么是子串？**
- 连续的字符序列
- "abc"在"abcabcbb"中是子串
- "ac"不是子串（不连续）
- 示例："abc"、"bca"、"cab"都是，但"pwke"不是（题目明确说明）

**什么是"不含有重复字符"？**
- 每个字符最多出现一次
- "abc" ✓
- "aba" ✗（a重复）
- "bbb" ✗（b重复）

### 示例分析（必须理解）

**示例1: "abcabcbb"**
```
"abc" → 长度3 ✓
"bca" → 长度3 ✓
"cab" → 长度3 ✓
"abcabc" → 长度6 ✗（a重复）
最长是3
```

**示例2: "bbbbb"**
```
只能有一个'b'
最长是1（任何一个'b'）
```

**示例3: "pwwkew"**
```
"wke" → 长度3 ✓（不重复）
"pwke" → 不是子串（是子序列）
最长是3
```

## 暴力求解法（背诵版）

### 记忆口诀：
**"双层循环遍所有子串，HashSet查是否重复，更新最大长度"**

### 具体步骤（按顺序记忆）：

#### 第一步：外层循环（起点）
```java
int maxLength = 0;
for(int i = 0; i < s.length(); i++) {
    // 从i开始的所有子串
}
```

#### 第二步：内层循环（终点）
```java
for(int i = 0; i < s.length(); i++) {
    Set<Character> set = new HashSet<>();  // 存储当前子串的字符

    for(int j = i; j < s.length(); j++) {
        char c = s.charAt(j);

        // 发现重复字符，跳出
        if(set.contains(c)) {
            break;
        }

        set.add(c);  // 无重复，加入set
        maxLength = Math.max(maxLength, j - i + 1);  // 更新最大长度
    }
}
```

#### 第三步：返回结果
```java
return maxLength;
```

### 完整代码框架
```java
public int lengthOfLongestSubstring(String s) {
    int maxLength = 0;

    for(int i = 0; i < s.length(); i++) {
        Set<Character> set = new HashSet<>();

        for(int j = i; j < s.length(); j++) {
            char c = s.charAt(j);

            if(set.contains(c)) {
                break;  // 找到重复，不再延伸
            }

            set.add(c);
            maxLength = Math.max(maxLength, j - i + 1);
        }
    }

    return maxLength;
}
```

## 优化方法：滑动窗口（加分项）

### 为什么需要优化？
暴力法时间复杂度O(n²)，不够高效

### 滑动窗口思想（必须记住）
```
窗口 = 当前子串的范围 [left, right]
无重复字符时：窗口向右扩大（right++）
发现重复字符时：窗口左侧收缩（left++）
窗口滑动过程中始终无重复
```

### 记忆口诀：
**"快慢指针成窗口，HashMap记位置，右移扩大左收缩，更新最大长度"**

### 滑动窗口步骤（按顺序记忆）：

#### 第一步：初始化
```java
int maxLength = 0;
int left = 0;  // 左指针
HashMap<Character, Integer> map = new HashMap<>();  // key=字符, value=上一次的索引+1
```

#### 第二步：右指针遍历
```java
for(int right = 0; right < s.length(); right++) {
    char c = s.charAt(right);

    // 如果字符已经在窗口中，移动左指针
    if(map.containsKey(c)) {
        left = Math.max(left, map.get(c));
    }

    // 更新最大长度
    maxLength = Math.max(maxLength, right - left + 1);

    // 记录字符的下一个位置（当前索引+1）
    map.put(c, right + 1);
}
```

#### 第三步：返回结果
```java
return maxLength;
```

### 滑动窗口完整代码（必须背）
```java
public int lengthOfLongestSubstring(String s) {
    int maxLength = 0;
    int left = 0;
    Map<Character, Integer> map = new HashMap<>();

    for(int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);

        if(map.containsKey(c)) {
            left = Math.max(left, map.get(c));
        }

        maxLength = Math.max(maxLength, right - left + 1);
        map.put(c, right + 1);
    }

    return maxLength;
}
```

## 面试时快速记忆要点

### 暴力法分析（易记）：
1. **双层循环**：模拟所有子串
2. **HashSet检查**：O(1)时间判断是否重复
3. **更新最大值**：Math.max比较

**时间复杂度**：O(n²)
**空间复杂度**：O(min(n, 字符集大小))

### 优化的滑动窗口分析（加分）：
1. **一个for循环**：右指针遍历
2. **HashMap记录**：字符→位置+1
3. **左指针跳跃**：遇到重复直接跳到上一次出现位置之后

**时间复杂度**：O(n)（最坏情况每个字符访问2次）
**空间复杂度**：O(字符集大小)

## 面试话术模板

**当被问到这道题时，可以这样回答：**

**【先说暴力法】**
> "这道题要求找最长无重复字符的连续子串长度。我的一个直观思路是使用暴力法：遍历所有子串，检查每个子串是否有重复字符。
>
> 具体来说，我使用两个循环，外层循环确定子串的起始位置，内层循环扩展子串的结束位置。在内层循环中，我用一个HashSet来保存当前子串中出现的字符。一旦发现重复字符，就跳出内层循环。同时在内层循环中更新最大长度。
>
> 这个方法的时间复杂度是O(n²)，因为有两层循环。空间复杂度是O(min(n, 字符集大小))，因为在最坏情况下字符集合的大小就是子串的最大长度。"

**【补充优化方案】**
> "其实这个题还可以用滑动窗口来优化。我只维护一个窗口，用两个指针left和right表示窗口的左右边界。right指针向右扩展窗口，如果遇到重复字符，就把left指针移动到重复字符上一次出现的位置之后。这样每个字符最多访问两次，时间复杂度降低到O(n)。
>
> 我可以用HashMap来存储每个字符最后一次出现的位置，这样左指针的跳转就是O(1)时间。这个优化思路在面试中可能更加分。"

## 代码模板（面试时先写框架）

**先写最容易理解的暴力法：**
```java
public int lengthOfLongestSubstring(String s) {
    int maxLength = 0;

    for(int i = 0; i < s.length(); i++) {
        Set<Character> set = new HashSet<>();

        for(int j = i; j < s.length(); j++) {
            char c = s.charAt(j);

            if(set.contains(c)) {
                break;
            }

            set.add(c);
            maxLength = Math.max(maxLength, j - i + 1);
        }
    }

    return maxLength;
}
```

**如果面试官要求优化，再写滑动窗口：**
```java
public int lengthOfLongestSubstring(String s) {
    int maxLength = 0;
    int left = 0;
    Map<Character, Integer> map = new HashMap<>();

    for(int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);

        if(map.containsKey(c)) {
            left = Math.max(left, map.get(c));
        }

        maxLength = Math.max(maxLength, right - left + 1);
        map.put(c, right + 1);
    }

    return maxLength;
}
```

## 常见问题和变种（准备）

### Q1: 如果要求返回子串本身，而不是长度？
```java
// 改动：在更新maxLength时记录起始位置
if(right - left + 1 > maxLength) {
    maxLength = right - left + 1;
    start = left;  // 记录起始位置
}
// 最后return s.substring(start, start + maxLength);
```

### Q2: 如果有多个相同结果？
- 只需要长度，所以不用管
- 如果要返回子串，返回任意一个都可以

### Q3: 字符集限制？
- ASCII → HashMap大小256
- Unicode → HashMap自动扩展
- 空间复杂度O(min(n, m))，m是字符集大小

### Q4: 如果要求最小子串？
- 把compareTo反过来
- 或者用最小堆
