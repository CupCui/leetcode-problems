# 第五题：拼接最大整数

## 题目要点背诵

### 核心目标（必须记住）
- 重新排列一组数字的顺序
- 最大值排在最前面（最高位）
- 每个数字**不能拆**（必须是完整的）
- 拼接成最大的整数

### 核心注意点（必须记住）
1. **返回字符串**：
   - 结果可能非常大
   - 必须使用String类型
   - 防止溢出

2. **边界条件**：
   - 数组长度为1 → 直接返回该数字字符串
   - 多个0 → "00..." → 应该返回"0"（一个零）
   - 前置0问题 → 特殊处理

### 示例分析（必须理解）

**示例1： `[10, 2]`**
- 可能组合：**102** vs **210**
- 为什么210更大？
  - 比较首位：2 > 1
  - 所以2要排在10前面

**示例2： `[3,30,34,5,9]`**
- 排序后：9, 5, 34, 3, 30
- 实际拼接：9534330
- 关键决策：**3 vs 34** vs **30**
  - 3+34=334, 34+3=343 → 34排前面
  - 3+30=330, 30+3=303 → 3排前面

## 暴力求解法（背诵版）

### 记忆口诀：
**"两两比拼接，谁大谁排前，全部比完后，连接成字符串"**

### 具体步骤（按顺序记忆）：

#### 第一步：转换类型（重要）
```java
// 将int[]转换为String[]，方便拼接比较
String[] strNums = new String[nums.length];
for(int i = 0; i < nums.length; i++) {
    strNums[i] = String.valueOf(nums[i]);
}
```

#### 第二步：自定义排序（核心逻辑）
```java
// 使用Arrays.sort() + 自定义Comparator
Arrays.sort(strNums, new Comparator<String>() {
    @Override
    public int compare(String a, String b) {
        // 关键：比较a+b和b+a
        String s1 = a + b;
        String s2 = b + a;

        // 按降序排列，所以s2和s1比较
        return s2.compareTo(s1);
    }
});
```

#### 第三步：拼接结果
```java
// StringBuilder提高效率
StringBuilder result = new StringBuilder();
for(String s : strNums) {
    result.append(s);
}
```

#### 第四步：处理特殊情况（重要）
```java
// 处理[0,0,0]这种结果变成"000"的情况
if(result.charAt(0) == '0') {
    return "0";
}

return result.toString();
```

## 核心思想解释

### 为什么比较a+b和b+a？

**直观理解：**
- 比如比较3和30
- 两种排法：**330** vs **303**
- 哪个排前面，拼接结果更大就排前面
- 所以330 > 303 → **3应该在30前面**

**规则总结：**
- 如果 `a+b > b+a` → a排在b前面
- 否则 → b排在a前面

### 如果记不住，就记住这个例子：

```
比较：3 和 30
方法："330" 和 "303"
结果："330" > "303"
结论：3 要排在 30 前面
```

- 主导：排序时间

### 空间复杂度：O(n)
- 存储字符串数组
- StringBuilder的结果

> 这个算法的时间复杂度是O(n log n)，主要由排序决定；空间复杂度是O(n)，用于存储字符串数组。"

## 关键比较逻辑（必须记住）

### Comparator的核心代码：
```java
// Lambda表达式版本（Java 8+）
Arrays.sort(strNums, (a, b) -> (b + a).compareTo(a + b));

// 传统版本（易记）
Arrays.sort(strNums, new Comparator<String>() {
    public int compare(String a, String b) {
        return (b + a).compareTo(a + b);
    }
});
```

### 为什么用`b+a.compareTo(a+b)`?
- 排序默认由小到大
- 这里要由大到小（最大在前面）
- 所以反过来比较

## 代码模板（面试时先写框架）

```java
public String largestNumber(int[] nums) {
    // 1. 边界检查
    if(nums == null || nums.length == 0) return "";

    // 2. 转字符串数组
    String[] strNums = new String[nums.length];
    for(int i = 0; i < nums.length; i++) {
        strNums[i] = String.valueOf(nums[i]);
    }

    // 3. 自定义排序（背下这一行）
    Arrays.sort(strNums, (a, b) -> (b + a).compareTo(a + b));

    // 4. 拼接结果
    StringBuilder sb = new StringBuilder();
    for(String s : strNums) {
        sb.append(s);
    }

    // 5. 处理全0情况（重要！）
    String result = sb.toString();
    if(result.charAt(0) == '0') {
        return "0";
    }

    return result;
}
```

## 边界情况处理（必须准备）

### 1. 单个数字
```java
输入: [5]
输出: "5"
处理: 正常排序，直接返回
```

### 2. 多个0
```java
输入: [0, 0]
输出: "0"（不是"00"）
处理: result.charAt(0) == '0' → return "0"
```

### 3. 包含0和其他数字
```java
输入: [0, 30, 3]
排序: 30, 3, 0（因为是330 vs 303, 33 vs 323, 30 vs 030）
输出: "330"
```

### 4. 数字位数不同
```java
输入: [999, 99, 9]
排序: 9, 999, 99（因为是99 > 99, 9999 > 9999, 99 > 99）
输出: "9999999"（9+999+99=9999999）
```

## 复杂例子演练（面试前练习）

### 例子：`[3,30,34,5,9]`

**步骤1：转字符串**
```java
strNums = ["3", "30", "34", "5", "9"]
```

**步骤2：排序过程**

- 最终顺序: 9, 5, 34, 3, 30

```java
result = "9" + "5" + "34" + "3" + "30"

```

## 与其他语言特化的比较（加分项）

**Python中的写法：**
```python
# 简洁的写法（记住思路）
def largestNumber(self, nums):
    return str(int(''.join(sorted(map(str, nums), key=lambda x, y: cmp(y+x, x+y))))
```

**JavaScript中的写法：**
```javascript
function largestNumber(nums) {
    return nums.map(String).sort((a, b) => (b+a) - (a+b)).join('');
}
```

**总结：**
- 不管什么语言，核心都是**比较a+b和b+a**
- 这是通用的算法思想

## 常见问题解答（准备）

**Q1: 为什么不直接把数组排序？**
A: 因为30和3相比，直接比较得到30 > 3，但是拼接出来"303" < "330"

**Q2: 为什么要转字符串？**
A: 1. 结果可能溢出 2. 方便拼接比较 3. 字典序比较符合要求

**Q3: 这道题的时间复杂度？**
A: O(n log n)，主要由排序决定。

**Q4: 如果全是0怎么处理？**
A: 拼接后检查首位，如果是0就返回"0"。
