# 第四题：寻找最大公共字符串因子

public class ProblemList {
    /**
     * ４、对于两个字符串s和t，我们说"t能整除s"当且仅当s = t + t + t + ... + t + t（即，t被自身连接一次或多次）。
     *
     * 给定两个字符串str1和str2，返回最大的字符串x，使得x既能整除str1也能整除str2。
     * 示例1:
     * 输入:str1="ABCABC"，str2="ABC"输出:"ABC"
     * 示例2:
     * 输入:Str1="ABABAB"，Str2 ="ABAB"输出:"AB"
     * 难度：中等
     *
     */
}

## 题目要点背诵

### 核心概念理解（必须记住）

**定义理解：**
- "t能整除s" → s = t + t + t + ... + t（t重复多次得到s）
- 关键点：**t是s的循环节**

**示例分析（必须记住）：**
-  `"ABCABC"` ：`"ABC"` × 2次 → 所以`"ABC"`能整除它
-  `"ABABAB"` ：`"AB"` × 3次或`"ABABAB"` × 1次 → 最大因子是`"AB"`

### 解题思路（核心）

**关键观察：**
- 如果x能整除str1，那么str1就是x重复拼接的结果
- 因此，**str1必须由若干个相同的子串组成**
- 最大的公共因子，就是两个字符串共有的循环节中最长的那个

**数学理解（背诵）：**
- 长度关系：`|x|`必须能同时整除`|str1|`和`|str2|`
- 公因数的长度就是最可能的最大因子长度

## 暴力求解法（背诵版）

### 记忆口诀：
**"长度公因数，从大到小试，重复能还原，找到就返回"**

### 具体步骤（按顺序记忆）：

#### 第一步：找出所有可能的长度
```java
// 获取两个字符串长度
int len1 = str1.length();
int len2 = str2.length();

// 找出可能的因子长度（必须是两个长度的公因数）
List<Integer> possibleLengths = new ArrayList<>();

for(int i = 1; i <= Math.min(len1, len2); i++) {
    if(len1 % i == 0 && len2 % i == 0) {
        possibleLengths.add(i);  // i是两个长度的公因数
    }
}
```

#### 第二步：从大到小尝试每个长度
```java
// 从大到小排序（Collections.reverse()或倒序遍历）
Collections.sort(possibleLengths, Collections.reverseOrder());

for(int candidateLen : possibleLengths) {
    String candidate = str1.substring(0, candidateLen);

    // 验证candidate是否能整除str1和str2
    if(canDivide(candidate, str1) && canDivide(candidate, str2)) {
        return candidate;  // 找到最大的，直接返回
    }
}

return "";  // 没有找到
```

#### 第三步：验证方法（核心逻辑）
```java
// 验证candidate是否能整除target
public boolean canDivide(String candidate, String target) {
    int candidateLen = candidate.length();
    int targetLen = target.length();

    // 如果长度不能整除，直接返回false
    if(targetLen % candidateLen != 0) {
        return false;
    }

    StringBuilder sb = new StringBuilder();
    int repeatCount = targetLen / candidateLen;

    // 重复candidate repeatCount次
    for(int i = 0; i < repeatCount; i++) {
        sb.append(candidate);
    }

    // 比较是否相等
    return sb.toString().equals(target);
}
```

## 面试时快速记忆要点

### 核心算法逻辑（三句话）：
1. **找出所有公因数长度**：能同时整除两个字符串长度的数
2. **从大到小尝试**：从大因子开始试，找到就返回（贪心策略）
3. **判断能否整除**：重复拼接候选串，看能否还原原串

### 时间复杂度（必须说出来）
- 设n = min(|str1|, |str2|)
- 找公因数：O(n)
- 验证过程：每次验证需要O(|str1| + |str2|)
- 最坏情况：O(n²)（需要验证所有公因数）

### 空间复杂度（必须说出来）
- O(|str1| + |str2|)：存储重复拼接的字符串
- 可以用StringBuilder优化

>

>
> 所以我的算法分为三步：第一步，找出所有能同时整除str1和str2长度的公因数；第二步，按照从大到小的顺序，尝试每个公因数对应长度的前缀串；第三步，对这个候选串进行验证，看看它重复若干次后是否能分别还原str1和str2。
>
> 在验证时，我会先检查长度是否能整除，然后重复拼接候选串，最后和原串比较。如果第一次验证成功（从大到小的顺序），就立即返回这个结果，这就是最大的公共因子。
>
> 这个算法的时间复杂度是O(n²)，因为我们可能需要验证多个公因数长度。空间复杂度是O(n)，主要消耗在字符串拼接上。不过这个算法思路清晰，代码实现也比较简单。"

## 关键验证逻辑（必须记住）

### 验证方法的核心代码（背诵）：
```java
// 验证candidate是否能整除target
public boolean canDivide(String candidate, String target) {
    int cLen = candidate.length();
    int tLen = target.length();

    if(tLen % cLen != 0) return false;  // 第一个判断

    StringBuilder sb = new StringBuilder();
    for(int i = 0; i < tLen / cLen; i++) {
        sb.append(candidate);  // 循环拼接
    }

    return sb.toString().equals(target);  // 最后比较
}
```

**记忆要点：**
- 长度不兼容 → false
- 重复拼接 → 创建新串
- 比较是否相等 → 保持一致性

## 常见问题和边界情况（必须准备）

1. **空字符串怎么办？**
   - 按照定义，空字符串可以整除任何字符串
   - 但根据题目通常要求非空

2. **一个字符串是另一个的子串**
   - 例如：str1="ABC", str2="ABCABCABC"
   - 答案应该是"ABC"

3. **没有公共因子**
   - 例如：str1="ABC", str2="DEF"
   - 返回空串"

4. **整个字符串本身作为因子**
   - str1="ABC", str2="ABC"
   - 返回"ABC"

**背诵一句话：** "因为要找最大的，所以从最大可能的长度开始尝试，一旦成功就返回。"

## 与其他算法的关系（加分项）

这个题目本质上与**最大公约数**问题类似：
- 字符串长度对应数值
- 循环整除对应倍数关系
- 找最大公共因子对应找GCD

可以说："这个问题的思路和求两个数的最大公约数类似，只不过是应用在了字符串的循环结构上。"
