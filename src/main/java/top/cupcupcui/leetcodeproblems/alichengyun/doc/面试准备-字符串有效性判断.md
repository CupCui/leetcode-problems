# 第三题：判断括号字符串是否有效

public class ProblemList {
    /**
     * 3、给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。
     * 有效字符串需满足：
     * 左括号必须用相同类型的右括号闭合。
     * 左括号必须以正确的顺序闭合。
     * 每个右括号都有一个对应的相同类型的左括号。
     * 难度：简单
     */
}

## 题目要点背诵

### 核心规则（必须记住）
1. **类型匹配**：左括号必须用相同类型的右括号闭合
   - `(` 只能匹配 `)`
   - `{` 只能匹配 `}`
   - `[` 只能匹配 `]`

2. **顺序匹配**：左括号必须以正确的顺序闭合
   - 正确：`()`、`[]`、`{}`
   - 错误：`) (`、`} {`、`] [`

3. **基本规则**：每个右括号必须有对应的左括号
   - 不能多右括号：`())`
   - 不能多左括号：`(()`

### 有效例子（记住）
- `"()"` ✓
- `"()[]{}"` ✓
- `"{[]}"` ✓
- `"([{}])"` ✓

### 无效例子（记住）
- `"(]"` ✗（类型不匹配）
- `"([)]"` ✗（顺序不正确）
- `"(("` ✗（右括号少了）
- `")))"` ✗（左括号少了）

## 暴力求解法（背诵版）

### 核心数据结构（必须记住）
```java
Stack<Character> stack = new Stack<>();

// 为什么用栈？
// 先进后出（LIFO）特性完美匹配括号嵌套关系
// 后出现的左括号要先闭合
```

### 记忆口诀：
> **"遇到左括号就入栈，见到右括号就匹配，匹配成功就弹出，匹配失败就返回false，最后检查栈是否为空"**

### 具体步骤（按顺序记忆）：

#### 第一步：遍历字符串中的每个字符
```java
for(char c : s.toCharArray()) {
    // 逻辑处理
}
```

#### 第二步：判断字符类型
```java
// 如果是左括号（"("、"{"、"["）
if (c == '(' || c == '{' || c == '[') {
    stack.push(c);  // 入栈
}

// 如果是右括号（")"、"}"、"]"）
else {
    // 处理右括号
}
```

#### 第三步：处理右括号（关键逻辑）
```java
else {
    // 先检查栈是否为空（没有左括号可以匹配）
    if(stack.isEmpty()) {
        return false;  // 多了右括号
    }

    // 弹出栈顶元素进行匹配
    char left = stack.pop();

    // 检查是否匹配（三种不匹配的情况）
    if((c == ')' && left != '(') ||
       (c == '}' && left != '{') ||
       (c == ']' && left != '[')) {
        return false;  // 类型不匹配
    }
}
```

#### 第四步：最后检查栈
```java
// 遍历完所有字符后
return stack.isEmpty();  // 栈空说明全部匹配成功
```

## 面试时快速记忆要点

### 核心算法逻辑（三句话）：
1. **左括号一律入栈**
2. **右括号一律匹配**
   - 如果栈空 → 多右括号 → 返回false
   - 如果匹配 → 弹出栈顶
   - 如果不匹配 → 返回false
3. **遍历完检查栈**
   - 栈空 → true（全部匹配）
   - 栈不空 → 多左括号 → false

### 时间复杂度：O(n)（必须说出来）
- 只遍历字符串一次
- 每个字符处理一次

### 空间复杂度：O(n)（必须说出来）
- 最坏情况下（全是左括号）栈的大小等于字符串长度
- 最好情况下（空字符串或匹配良好）栈很小

## 面试话术模板

**当被问到这道题时，可以这样回答：**

> "这道题我的思路是使用**栈**这个数据结构来解决。因为括号的匹配遵循**后进先出**的原则，后出现的左括号必须**先**被闭合。
>
> 具体做法是：我先创建一个栈，然后遍历字符串中的每个字符。如果遇到左括号（包括圆括号、方括号、花括号），我就将其**入栈**；如果遇到右括号，我就从栈中**弹出**栈顶元素进行匹配。
>
> 匹配时有三种情况：第一，如果栈已经为空，说明没有对应的左括号，直接返回false；第二，如果弹出的左括号与当前右括号**类型不匹配**，也返回false；第三，如果匹配成功，就继续遍历。
>
> 遍历完整个字符串后，我再检查一下栈是否为空。如果为空，说明所有左括号都找到了匹配的右括号，返回true；如果不为空，说明有多余的左括号，返回false。
>
> 这个算法的时间复杂度是O(n)，因为我们只遍历一次字符串；空间复杂度也是O(n)，用于存储栈。"

## 代码模板（面试时先写框架）

```java
public boolean isValid(String s) {
    // 1. 创建栈
    Stack<Character> stack = new Stack<>();

    // 2. 遍历字符串
    for(char c : s.toCharArray()) {
        // 3. 判断是左括号还是右括号
        if(c == '(' || c == '{' || c == '[') {
            stack.push(c);  // 左括号入栈
        } else {
            // 右括号处理
            if(stack.isEmpty()) return false;  // 没有左括号可匹配

            char left = stack.pop();  // 弹出栈顶

            // 检查是否匹配（三种不匹配情况）
            if((c == ')' && left != '(') ||
               (c == '}' && left != '{') ||
               (c == ']' && left != '[')) {
                return false;
            }
        }
    }

    // 4. 最后检查栈是否为空
    return stack.isEmpty();
}
```
